# Where to start

Moved out of `CLAUDE.md` so it costs nothing until it is needed. Grep it for the thing you are changing
(`grep -i 'meal plan' docs/routing.md`) rather than reading it end to end; most work lands in one of the
files a row names. A row that names a `docs/arch/` file means reading that file is not optional before
changing the area: start with its "Rules first" block where it has one, then the sections it cites.

For anything not listed, `docs/module-map.md` lists every logic module and what it exports, and
`docs/screen-map.md` says what each screen renders and where each component appears. Where a row
here names a file it is the authority: the two maps are indexes, not write-ups.
